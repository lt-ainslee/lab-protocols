# 50× TAE 缓冲液

| 项目 | 内容 |
|---|---|
| SOP 编号 | RG-001 |
| 版本 | v1.0 |
| 储存 | 室温，6 个月 |

## 配方（1 L）

| 成分 | 用量 |
|---|---|
| Tris 碱 | 242 g |
| 冰醋酸 | 57.1 mL |
| 0.5 M EDTA (pH 8.0) | 100 mL |
| 去离子水 | 补至 1 L |

!!! warning "注意"
    冰醋酸具有腐蚀性和刺激性气味，请在通风橱中量取。

## 步骤

- [ ] 将 Tris 碱溶于约 700 mL 去离子水
- [ ] 在通风橱中加入冰醋酸
- [ ] 加入 EDTA 溶液，定容至 1 L
- [ ] 使用前稀释 50 倍为 1× 工作液
